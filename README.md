# task-flow-cli
 A Python-based Command Line Interface (CLI) app where users add tasks, mark them done, track recurring habits, and save/load their data to a file — with a small stats report at the end. 


Project Structure
taskflow/

├── main.py          # entry point, menu loop, user I/O

├── task_utils.py    # module: helper functions, constants

└── data.txt          # saved tasks (created at runtime)
